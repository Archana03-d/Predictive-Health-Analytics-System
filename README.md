# Predictive Health Analytics System

## Project Overview
This project focuses on Exploratory Data Analysis (EDA), Outlier Detection, and Feature Engineering using a Heart Disease dataset.

The objective is to transform raw healthcare data into a clean and structured dataset ready for Machine Learning applications.

## Dataset
- Heart Disease Dataset
- 1025 records
- 14 features

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Tasks
- Data Loading and Inspection
- Missing Value Analysis
- Correlation Analysis
- Outlier Detection using IQR
- Outlier Handling
- Feature Engineering
- Data Visualization

## Engineered Features
1. Age_Group
2. Cholesterol_Level
3. Risk_Score
